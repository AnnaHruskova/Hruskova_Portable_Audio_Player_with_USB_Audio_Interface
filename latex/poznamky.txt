pozn.
SAI = HW rozhraní v STM32 pro digitální audio
    - Serial Audio Interface

I2S = konkrétní způsob, jak se audio data přenášejí
    BCLK  ─── bitový clock
    LRCLK ─── levý/pravý kanál
    DATA  ─── samotná audio data
    MCLK  ─── případně hlavní audio clock

    STM32 SAI                         DAC
    │                               │
    ├──── BCLK ────────────────────►│
    ├──── LRCLK ───────────────────►│
    ├──── DATA ────────────────────►│
    └──── MCLK ────────────────────►│

    - SAI můžu nakonfigurovat tak, aby komunikoval I2S protokolem

DMA = Direct Memory Access
    - neříká nic o formátu audia
    - přesouvá data mezi RAM a periferií, aniž by byl zapojen CPU

    bez DMA
        RAM → CPU → SAI → DAC
            ↑
        CPU pořád obsluhuje
        každý přenos

    s DMA
        RAM ───── DMA ─────► SAI ─────► DAC
                                ↑
        CPU mezitím dělá něco jiného
