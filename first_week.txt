microSD --> SDMMC 4bit --> STM32U575VIT6Q

                                --> SPI --> displej
                                --> USB-AudioClass (z PC jsou posílané po USB jen PCM vzorky)

                                PC ----USB audio, PCM data --> STM32 ----> SAI+DMA ---> DAC --> slcuhátka

    

- COMPOSITE DEVICE
    - ale je třeba pohlídat, kdy kdo má přístup k SD kartě
    	--> Pokud bude přes MSC počítači zpřístupněna stejná microSD, ze které zároveň STM32 čte FAT filesystem, nesmí PC a STM32 nezávisle zapisovat do stejného filesystemu.
    - normal mode STM32 vlasní SD kartu --> MP3 player
    --> připojení jako Mass Storage ==> STM32 filesystem unmount --> PC ovládá SD kartu
    --> odpojení USB 
            --> pc se odpojilo
            --> STM32 mount SD card
            --> scan music
            --> přehrávání


- VHODNÉ AUDIO kodeky  (DAC + ADC)
    - jednočipově = kodek + headphone amp v jednom čipu
        - max audio rate ale 48 kHz...
    - dvoučipově = kodek a headphone amp separátně
        - PCM5102APW — TSSOP-20 --> analogový výstup line level
        - TPA6111A2D — SOIC-8

        --> full audio kodek není potřeba, ADC část nebude využita (není tam vstup, mikrofon, nahrávání...)
        ┌─────────────────────┐     SAI / I²S      ┌──────────────┐      L / R      ┌──────────────┐      L / R      ┌───────────┐
        │ STM32U575VIT6Q      │ ─────────────────▶ │ PCM5102A     │ ─────────────▶ │ TPA6111A2    │ ─────────────▶ │ 3.5 mm TRS│
        │                     │                    │ TSSOP-20     │                 │ SOIC-8       │                 │ jack      │
        │ MP3 → PCM           │                    │ stereo DAC   │                 │ headphone amp│                 │           │
        └─────────────────────┘                    └──────────────┘                 └──────────────┘                 └───────────┘
    
        --> PCM5102APW = stereo audio DAC
            --> přijme PCM vzorky z STM32 přes SAI (třeba přes I2S) a vytvoří z něl L a R kanál
            --> 32 bit / 384 kHz, dyn. range 112 dB, THD+N -94 dB
            - režimy se nastavují piny, není potřeba I2S/SAI konfiguraci DACu
            --> alternativa TI PCM5122 = nabízí I2C/SPI ovládání a digitální audio processing
        --> TPA6111A2D
            --> audio výkonový zesilovač
            --> obsahuje obvod pro omezení lupnutí při zapojení (HotPlug)
            --> využívá vstupní a výstupní vazební kondenzátory --> na PCB velké kondenzátory
                - při 32Ω sluchátkách dává 68µF výstupní kondenzátor dolní mez přibližně 73 Hz, pro větší basy bude potřeba větší kapacity
            
            - modernější headphone amplifiers jsou ale v QFN/BGA pouzdrech ...


-I2S-SAI - obsluha - HAL, jak DMA
    - DMA pingpong/double buffer
        - buffer A se přehrává, buffer B se plní, pak se přehrává B a A se plní...

    - WAV --> PCM buffer A,B --> DMA --> SAI --> I2S



- AUDIO výstup
    - 3,5mm sluchátkový výstup TRS stereo
    - zesilovač TPA6111A2
